Entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on [make.fun](https://make.fun).

`main.ts` writes one pickup line — spoken by a vending machine to a passing
human — to `/output/entry.txt`:

> You walked past twice today. My coil's jammed, my lights are flashing, and I still can't drop the hint.

The line was picked from 12 candidates drafted and scored in-session against
the judge brief (machine voice, machine world, punch in the last words,
short and speakable, charming not creepy). See [CANDIDATES.md](CANDIDATES.md).

Run it with Node 22:

```
node main.ts
```
